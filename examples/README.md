# Example data bundles

Small **synthetic** data bundles (simulated, not measurements) for the tutorial
[docs/tutorials/first_figure.md](../docs/tutorials/first_figure.md) and its CI test. They
are committed so the tutorial needs no download; `python examples/make_examples.py`
regenerates them byte for byte (fixed seed).

| Bundle | Data | `plot_type` (contract) |
|---|---|---|
| `dose_response/` | Viability (% of control) of 3 compounds x 7 doses x 4 replicates, four-parameter logistic curves plus noise | `line_band` (`core.line_band`) |
| `screen_hits/` | 400 features: effect size, two-sided z-test P, Benjamini-Hochberg adjusted P; 30 simulated true hits | `threshold_scatter` (`core.threshold_scatter`) |

Each bundle follows the table bundle contract
([docs/contracts/table_bundle_contract.md](../docs/contracts/table_bundle_contract.md)):
`inputs/data.csv` plus `metadata/metadata.yaml` with `plot_type` and `plot_params`
(which columns are x, y, groups, ...). Real data go under `raw_data/` (git-ignored,
read-only); these examples are the only data in the repository.

## Gallery bundles (`gallery/`)

One small synthetic bundle per basic shape, generated by `python examples/make_gallery.py`
(fixed seed, byte-identical on re-run). Each is a starting point for your own figure: pick the
picture closest to what you need in the [renderer gallery](../docs/reference/gallery.md), copy
the folder under `raw_data/<project>/`, replace `inputs/data.csv` with your table (same column
names, or name yours in `plot_params`), then `fa bundle check`, `fa ingest bundle` and
`fa build --preflight`. The comment at the top of each `metadata.yaml` says what each column is.
A test (`tests/test_gallery_examples.py`) builds every one of them at single-column size and
requires preflight to report no error or warning.

| Bundle | Shape | Data |
|---|---|---|
| `boxplot/` | box plot | relative expression per treatment |
| `violin/` | violin plot | dendritic spine density per genotype |
| `histogram/` | histogram | cell diameter, two conditions |
| `line_band/` | line + error band | bacterial growth (OD600) over time, two strains |
| `dose_response/` | dose-response with 4PL fit | viability over dose, two compounds (EC50 in the source data) |
| `survival/` | Kaplan-Meier curves | survival of two groups of mice, with censoring |
| `stacked_bar/` | stacked bars (shares) | cell-type composition per sample |
| `threshold_scatter/` | volcano-type scatter | fold change and adjusted P per gene |
| `venn/` | Venn diagram | two gene lists |
| `multi_group_heatmap/` | clustered heatmap with groups | 20 genes x 9 samples in three groups |
| `image_panel/` | microscope image | two synthetic 16-bit channels with a scale bar |
