## 새 결정 쓰기

다음 번호로 `NNNN-짧은-이름.md`를 만들고(한국어판은 `NNNN-짧은-이름.ko.md`) 아래 형식을 따릅니다. 결정이 바뀌면 옛 기록을 지우지 않고 상태를 "대체됨 (→ NNNN)"으로 바꿉니다.

<!-- i18n: prose -->
```markdown
# NNNN. 결정 한 줄

- 상태: 채택 | 제안 | 대체됨 (→ NNNN)
- 날짜: YYYY-MM-DD

## 배경
무엇이 문제였나, 어떤 사실이 결정을 강제했나.

## 결정
무엇을 하기로 했나.

## 결과
좋아지는 것, 대가, 이 결정을 지키는 장치(테스트·명령·검사).
```
