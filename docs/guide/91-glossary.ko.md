# 부록 A. 용어집

가나다·알파벳 순입니다. 괄호 안은 영어 이름이나 파일·명령에 쓰이는 이름입니다.

| 용어 | 뜻 | 자세히 |
|---|---|---|
| **개편 기록** (revision) | 스토리라인을 바꿀 때마다 남기는 번호 붙은 기록. 무엇을, 왜 바꿨고, 근거 데이터가 무엇인지 적습니다. | 11장 |
| **Case A·B·C** | 새 그림을 들여오는 세 가지 길. A = 내가 짠 그림 코드 + 데이터, B = 규격 번들, C = 데이터 + 원하는 그림의 캡처·스케치·말 설명 | 5장 |
| **검증** (verify) | 결과물(그림 파일, 설명서, 통계표 등)이 빠짐없고 서로 맞는지 보는 검사. PASS / WARN / FAIL | 8장 |
| **계약서** (contract) | 그림 종류마다 번들에 어떤 열이 있어야 하는지 정한 규칙. 번들 검사가 이것으로 확인합니다. | 3장, [계약서 목록](../contracts/README.md) |
| **그림 설명 파일** (figure spec) | 그림 제목, 패널별 설명, 주장 범위를 적는 파일. `figure_specs/` 아래 | 2장, 7장 |
| **낡음 / 최신** (stale / fresh) | 그림을 만든 뒤 데이터·설정·프로그램이 바뀌었으면 낡음, 그대로면 최신 | 10장 |
| **렌더러** (renderer) | 그림 종류 하나를 그리는 프로그램 부품(선 + 오차 띠, 산점도, 히트맵 등). 연구자가 직접 다룰 일은 거의 없습니다. | — |
| **메모** (`metadata.yaml`) | 번들 안에서 "무슨 그림인지(`plot_type`)"와 처음 설정(`plot_params`)을 적은 파일 | 3장 |
| **번들** (bundle) | 패널 하나에 들어갈 데이터 폴더. 표(`data.csv`) + 메모(`metadata.yaml`) | 3장 |
| **보관 / 은퇴** (archive / retire) | 쓰지 않게 된 프로젝트를 지우지 않고 `archive/`로 옮기는 일 | 11장 |
| **빌드** (build) | 설정대로 그림을 다시 그리고, 정리하고, 검사하고, 기록하는 한 번의 실행 | 4장 |
| **살아 있는 숫자** (live number, claim) | 그림 설명 속 결과 숫자를 손으로 쓰지 않고 분석 결과로 채우는 방식. 설명에는 `{이름}`으로 씁니다. | 9장 |
| **설정 파일** (config) | 그림의 모든 값이 설명 주석과 함께 적힌 파일. 연구자가 그림을 고치는 곳 | 6장 |
| **스냅샷** (snapshot) | 스토리라인의 어느 시점 상태(배치, 그림 출처, 숫자)를 저장한 것. 나중에 비교할 때 씁니다. | 11장 |
| **스토리라인** (storyline) | 논문의 그림 배치(어느 프로젝트가 Figure 몇 번인지)와 이야기를 적은 문서 | 11장 |
| **승격** (promote) | 탐색 프로젝트를 논문 Figure 프로젝트로 옮기고 이름을 바꾸는 일 | 11장 |
| **연구 단위** (domain) | 프로젝트를 묶는 단위(연구자나 과제). 예: `lab`, `kim`, `screening` | 2장 |
| **인쇄 전 검사** (preflight) | 그림의 겹침·잘림·글자 크기·색·폰트 문제를 찾는 검사. error / warn / info | 8장 |
| **지문** (해시, sha256) | 파일 내용으로 계산한 고유한 문자열. 내용이 1바이트만 달라도 바뀝니다. | 10장 |
| **출처 기록** (provenance) | 그림이 어떤 데이터·설정·프로그램으로 언제 만들어졌는지 자동으로 남는 기록 | 10장 |
| **컴펜디움** (compendium) | 스토리라인의 모든 Figure를 순서대로 모은 PDF | 11장 |
| **탐색 / 논문 / 보관** (exploratory / paper / archive) | 프로젝트의 세 단계. 폴더 이름이기도 합니다. | 2장, 11장 |
| **패널** (panel) | 그림 안의 칸 하나(a, b, c, …) | 4장 |
| **패널 태그** (panel tag) | 패널 왼쪽 위의 a, b, c 글자. 패널의 바깥 경계에 맞춰 자동으로 붙습니다. | 4장 |
| **프로젝트** (project) | 그림 한 장을 만드는 단위. 설정·분석·그림 설명 파일 세 개 | 2장 |
| **AI 도우미 / 에이전트** (agent) | Claude Code, Gemini CLI 같은, 말로 시키면 도구를 대신 실행하는 AI | 12장 |
| **CI** | 저장소에 변경이 올라갈 때마다 자동으로 도는 검사. 규칙 위반을 막습니다. | — |
| **MCP** | AI 도우미가 외부 도구를 부르는 공통 방식. fig-atlas는 이것으로 도구를 내놓습니다. | [AI 연결](../howto/ai_agents.md) |
| **pt** (포인트) | 글자 크기·선 굵기 단위. 1 pt ≈ 0.35 mm | 6장 |
| **Source Data** | 그림에 실제로 그려진 값의 표. 일부 저널이 요구합니다. | 9장 |
| **YAML** | 설정 파일의 형식. `이름: 값`을 들여쓰기로 묶습니다. | 6장 |
